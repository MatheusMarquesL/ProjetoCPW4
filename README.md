Nome_Projeto: SPA_Biblioteca

Desc: Neste projeto irei fazer uma biblioteca virtual, para gerenciamento de livros.
Para gerenciar empréstimos e a movimentação dos livros, quantidade de leituras e leitores.
Visando ter uma interface prática para o uso do dia a dia.




Funcionalidades:

* Ferramenta de busca: Filtro em tempo real para localização de títulos no acervo.

* Cadastro de usuário: Criação de novas contas através de formulário dinâmico.

* Login e autenticação: Controle de acesso às rotas do sistema via estado global.

* Gerenciamento de livros: Visualização detalhada e listagem de obras disponíveis.

* Monitoramento de empréstimos: Espaço dedicado ao controle de movimentação dos itens.


Tecnologias Utilizadas:

* React.js: Biblioteca principal para construção da interface.

* React Router Dom: Gerenciamento de navegação entre páginas e rotas dinâmicas.

* SCSS: Estilização intermediária com uso de variáveis e arquitetura modular.

* Context API: Gerenciamento de estado global para autenticação e dados da biblioteca.


Estrutura e Organização: 

* Components: Armazena elementos reutilizáveis como a Navbar.

* Pages: Contém as telas principais da aplicação (Login, Home, Detalhes).

* Context: Centraliza a lógica de dados e segurança do sistema.

* Styles: Agrupa os arquivos de estilização e variáveis de cores
