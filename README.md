Nome_Projeto: SPA_Biblioteca

Desc: Neste projeto irei fazer uma biblioteca virtual, para gerenciamento de livros.
Para gerenciar empréstimos e a movimentação dos livros, quantidade de leituras e leitores.
Visando ter uma interface prática para o uso do dia a dia.

Funcionalidades:

* Ferramenta de busca
* Cadastro de usuário
* Login e autenticação
* Upload de livros 
* Gerenciamento de livros
* Monitoramento de empréstimos
